# 一、Peng 2023：监督对比学习 + 负的分布外数据增强

## 1.1 一句话
用有标签的故障数据训练一个"紧凑"的特征空间，同时**人造一批"假的未知故障"**当负样本，让正常类的特征更紧，使未知故障更容易被判成"故障"，而不是被当成"正常"。

## 1.2 要解决什么问题
- 训练时只有"正常 + 若干已知故障"，上线后可能出现**没见过的故障**。
- 作者观察到（图 1，TE 数据）：**未知故障的样本和"正常"样本在特征空间里重叠**，无论用 softmax 还是监督对比损失都是这样。最危险的错误就是把新故障当成正常。
- 他们的思路：既然未知故障总是混进正常类里，那就**只需要把正常类压紧**。

## 1.3 流程（对应原文 Fig.4 和 Algorithm 2）
1. **预处理**：数据归一化到 [0, 1]。
2. **训练收缩自编码器（SAE）**：把已知数据压到一个低维"潜空间" h。
3. **在潜空间里生成"假未知"**：用 SBO（软布朗偏移）从已知样本出发，一步步往外"漂"，直到离所有已知数据足够远，得到 ĥ；再用解码器还原成原始空间的样本 X̂。这些就是**负的分布外样本（OOD）**。
4. **训练对比网络**：损失 = L1 + α·L2。
   - L1：对所有已知类做**监督对比损失**，让同类靠近、异类分开；
   - L2：把"已知故障 + 生成的 OOD"当成**同一个类**，和"正常"对比。结果是正常类被压得更紧。
5. **训练分类器**：在学到的特征上训练一个两层的 **(M+1) 类 softmax 分类器**，生成的 OOD 样本当作第 M+1 类。
6. **上线**：新样本被判为"正常 / 某已知故障 / 未知"。

## 1.4 基本函数（带小例子）

**(a) 自监督对比损失（原文式 1）**
```
L_self = −Σ_i log [ exp(z_i·z_j(i)/τ) / Σ_{a≠i} exp(z_i·z_a/τ) ]
```
- 意思：同一个样本的两个增强视图应该相似（正样本对），和其他所有样本不相似（负样本）。τ 是温度，越小越"苛刻"。
- 例子（τ=0.1）：一个锚点，正样本相似度 0.9，两个负样本相似度 0.1 和 0.2：损失 = −log[e⁹ / (e⁹+e¹+e²)] ≈ **0.0013**（几乎为 0，很好）。如果正样本相似度只有 0.3：损失 ≈ **0.408**（大，要继续训练）。

**(b) 监督对比损失（SupCon，原文式 2）**
```
L_sup = Σ_i  −1/|P(i)| · Σ_{p∈P(i)} log [ exp(z_i·z_p/τ) / Σ_{a≠i} exp(z_i·z_a/τ) ]
```
- 和 (a) 的区别：**同一类的所有样本都算正样本**，不只是自己的增强视图。
- 例子：锚点有 2 个同类样本（相似度 0.9、0.5）和 2 个异类样本（0.1、0.2），τ=0.1：对两个正样本分别算 −log 再平均，结果 ≈ **2.02**。相似度 0.5 的那个正样本拖高了损失，训练会把它拉近。

**(c) 自编码器和"收缩"自编码器（式 5、6）**
```
L_AE  = 1/n Σ ‖y_i − x_i‖²                      （重建误差）
L_SAE = 1/n Σ ‖y_i − x_i‖²  +  λ·1/n Σ ‖z_i‖²   （再惩罚潜变量的长度）
```
- 自编码器：编码器把 x 压成 z，解码器把 z 还原成 y，要求 y 接近 x。
- "收缩"：多加一项惩罚 ‖z‖²，让潜变量更集中，这样"已知数据"在潜空间里是一团紧的云，往外走一段距离就算"未知"。

**(d) 软布朗偏移 SBO（式 3、4，Algorithm 1）**
- 先从已知数据里随机抽一个点 x，然后反复做：沿一个随机方向（高斯超球面采样，式 3）走一小步 d₊；每走一步算它到已知数据集的最小距离 d*；直到 d* 超过设定的"最可能距离" d₋ 就停。
- "软"：每一步以概率 ρ 提前停，ρ 随 d* 增大而减小（式 4，κ=7，σ∈[0,1] 控制边界有多软）。
- 通俗理解：**一个喝醉的人从已知数据的某一点出发随机游走，走到离已知区域"不远不近"的地方停下**，就得到一个看起来像"没见过但又不太离谱"的样本。
- 两处排版疑点（**请核对原文，我没有核对 SBO 原论文**）：式 (4) 在我读到的版本里分子是 d*+d₋，按文字"d*=0 时 ρ 接近 1"推断应该是 d*−d₋；Algorithm 1 第 9 行写的 `μ<ρ`，应是 `u<ρ`。

**(e) (M+1) 类 softmax 与交叉熵（式 8、9）**
```
ŷ_ij = exp(w_j·f(z_i)+b) / Σ_{j=1}^{M+1} exp(w_j·f(z_i)+b)
L = −Σ_i Σ_j y_ij · log ŷ_ij
```
- 就是普通的分类，只是多了第 M+1 类"生成的未知"。

**(f) 开放空间风险（式 10）**
- 简单说：已知类周围**不属于任何已知类的空白空间**越大，未知样本落进去被误当成已知的风险越大。生成负样本相当于把这片空白"填上标签"。

**(g) 评价指标**
- **AUROC**：随机挑一个已知样本和一个未知样本，已知的分数更高的概率。例子：已知分数 0.9、0.8、0.7，未知分数 0.6、0.75、0.2：9 对里 8 对排对，AUROC = 0.889。
- **检测率**：未知故障里被正确判成"未知"的比例（相当于我们的"未知召回"）。
- **softmax 加阈值**（基线）：最大概率低于 0.2 就判未知。**OpenMAX**、**EVM**（极值机，基于极值理论）是另两个经典开集基线。

## 1.5 实验设置和文字里的结果
- **数据**：Tennessee Eastman 过程（TE，化工过程仿真，不是振动信号）：故障 1、2、4、6、7 当已知，故障 8、12、14、18 当未知（18 最难）；以及一个**真实等离子刻蚀过程**数据（12 个过程变量，623 个样本：600 正常、故障各 8/5/10 个）。
- **三种设定**：均衡、不均衡（每个故障只有 50 个样本，10:1）、小样本（每个已知故障 15 个）。
- **对比方法**：softmax+阈值、OpenMAX、EVM、SBO–SCL（直接把生成的 OOD 当新类）。
- **文字里的数字**（百分数是相对提升）：均衡设定下，故障 8 的 AUROC 比这四个方法分别高 8.34%、6.34%、4.92%、0.05%；小样本下检测率：故障 8/12/14/18 分别 95.1%、97.6%、99.86%、88.2%；故障 18 的 AUROC 比四个方法高 11.11%、10.29%、8.56%、0.51%。等离子刻蚀：AUROC 85.91 / 87.98 / 90.87 / 95.51 / 100%，检测率 0 / 55 / 70 / 85 / 100%。
- **读数据时要注意**：和 SBO–SCL 的差距很小（AUROC 只高 0.05% 到 0.51%），主要优势来自"生成负样本 + 对比学习"，紧凑损失只是锦上添花；刻蚀实验的测试集每类只有 20 个样本，100% 的说服力有限。我没有读到重复实验或标准差的说明（可能在表里）。

## 1.6 创新点
作者声称的：
1. 把**监督对比学习**用到开集故障诊断；
2. 用 **SBO + 收缩自编码器**在潜空间生成负的 OOD 样本，用在训练里；
3. 增加"**把已知故障和生成的 OOD 当成一类，对比正常类**"的辅助任务，让正常类更紧凑；
4. 在三种实际设定（均衡 / 不均衡 / 小样本）下验证。

来源要分清：SCL 来自 Khosla 等（2020），SBO 来自 Möller 等（2021），收缩自编码器是已有做法。**真正新的是它们的组合和第 3 点的"紧凑损失"**。

## 1.7 局限（作者自己写的 + 我的看法）
- 作者承认：性能取决于生成的 OOD 质量；如果未知故障在完全有监督的情形下都很难和已知类分开，这个方法也很难检测。
- 假设"未知故障会和正常样本重叠"。
- 我的看法：数据是**过程变量**，不是高频振动；是否适用于振动信号，没有验证。训练用的是**全部带标签**的已知类数据。

# 二、Zhao 2022：自适应开集域泛化网络（AOSDGN）

## 2.1 一句话
在**多个工况**（不同载荷、转速）的带标签数据上训练，测试时遇到**没见过的工况，而且出现没见过的故障**，同时做到"已知故障分对"和"未知故障识别出来"。

## 2.2 要解决什么问题
- 前人的"域泛化"假设训练和测试的故障类别相同，只是工况不同；"开集"方法又假设分布相同。
- 现实中**两个变化同时发生**（分布偏移 + 标签偏移），文章把它叫做**开集域泛化故障诊断（OSDGFD）**，作者称在智能故障诊断里他们没有查到前人研究。
- 设定：多个**源域**（每个工况是一个域，有标签）；**目标域**（没见过的工况）训练时完全不能用；目标域里有源域没有的故障。

## 2.3 流程（原文 Fig.2，算法 1）
1. 输入：多个源域（不同工况）的带标签样本。
2. **一维 CNN 特征提取器**把每个样本变成嵌入 z。
3. **局部类聚类（三元组损失）**：同类样本不论来自哪个工况都拉近，异类推远。目的是得到对工况不变、对类别可分的特征，并把已知类"推到特征空间外围"，给未知故障留出中心空间。
4. **类别自适应决策边界**：每个已知类计算**原型** c_n（该类嵌入的平均），再给每个类学一个**自己的半径** Δ_n。已知样本应该落在以 c_n 为球心、Δ_n 为半径的球里。
5. **三项损失联合训练**：L = L_c（源域分类交叉熵）+ β·L_a（边界损失）+ γ·L_t（三元组损失），用 Adam，端到端。（式子是我根据文字重建的，文字写"β 和 γ 是平衡三项损失的两个系数"。）
6. **推理**：测试样本 z 到各个类原型的欧氏距离，如果落进某个类的球（半径乘以一个缩放系数 δ）就判为那个已知类，**不在任何球里就判为未知**。（δ 具体怎么用，原文被机翻弄乱了，我是推测的。）

## 2.4 基本函数（带小例子）

**(a) 三元组损失（局部类聚类）**
- 三元组：锚点 a、正样本 p（同类）、负样本 n（异类）。损失（标准形式，**重建**）：
  `L = Σ [ d(a,p) − d(a,n) + ξ ]₊`，ξ 是间隔，[·]₊ = max(0, ·)。
- 三种三元组：
  - **容易**：负样本已经比正样本远 ξ 以上，损失为 0，不用学；
  - **半难**：负样本比正样本远，但不到 ξ；
  - **难**：负样本反而比正样本更近。
  文章**只优化半难和难的**。
- 例子（ξ=0.5）：d(a,p)=0.8、d(a,n)=1.0：半难，损失 0.3；d(a,p)=0.3、d(a,n)=1.5：容易，损失 0；d(a,p)=1.0、d(a,n)=0.7：难，损失 0.8。

**(b) 类原型**
- c_n = 第 n 类所有样本嵌入的平均向量。

**(c) 可学习半径与 softplus**
- 每个类一个可学习参数，经过 softplus 变成正数：Δ_n = log(1+e^{x_n}) > 0。例子：x=−2 → 0.127；x=0 → 0.693；x=1 → 1.313。保证半径永远是正数。
- **初始半径通常很小**，装不下已知样本，训练中被拉大（原文图 12a）。

**(d) 边界损失（重建，原文公式没读出来）**
- 文字描述：已知样本落在球外，经验风险上升，所以要**扩大半径**；已知样本离原型很近、球过大，未知样本也可能落进来，开放空间风险上升，所以要**收缩半径**。最终半径包住大多数已知样本，又不离原型太远。这个做法来自 Zhang 等人 2021 的"自适应决策边界"（参考文献 38），具体公式请看英文原文。
- 判断例子：原型在 (0,0)，半径 1.2；样本 (0.9, 0.5) 距离 1.03，在球内，判已知；样本 (2, 1) 距离 2.24，在球外，判未知。

**(e) 评价指标 H-score**
```
OS* = 已知类的准确率，UK = 未知类的准确率，H = 2·OS*·UK / (OS* + UK)
```
- 调和平均：两个都高才高。例子：OS*=0.9，UK=0.6 → H=0.72。**这和我们课题里用的 H 是同一个指标。**

**(f) 其他术语**
- **域适应 vs 域泛化**：域适应训练时需要目标域的（无标签）数据；域泛化完全不用。
- **EVT 极值理论**、**LOF 局部离群因子**：两个经典的离群检测方法，作为对比的"开集部分"。
- **ADIG**（对抗域不变泛化）、**CNN-C**（带中心损失的 CNN）：两个域泛化对比方法。
- 对比方法 M1–M6 应该是 {基线 CNN、ADIG、CNN-C} × {EVT、LOF} 的六种组合（原文这一段机翻不够清楚，我是推测的）。消融 D1（检验类别自适应边界）和 D2（检验局部类聚类）具体去掉了什么，文字里没写清楚。

## 2.5 实验设置和文字里的结果
- **齿轮箱**：一级减速箱，驱动齿轮有 4 种径向裂纹长度（无、1/4、1/2、3/4）；4 种载荷 4、6、8、10 Nm；采样 5 kHz。
- **轴承**：SpectraQuest 机械故障模拟器，5 种状态（正常、内圈、外圈、滚动体、复合故障），4 种转速 60、65、70、80 Hz，采样 25.6 kHz；每个状态每个工况 800 个训练样本、200 个测试样本，每个样本 1024 点，**用 FFT 提取频率特征后建模**。
- **任务**：设计了 20 个 OSDGFD 任务；训练 100 个 epoch，批大小 1024，Adam，学习率 0.001/(1+10p)^0.75，2080Ti，十次平均。
- **文字里的结果**：文中写"平均精度"齿轮箱 88.75%、轴承 79.65%（应该是表 5、表 6 的 H-score 平均，具体表格没读到）；已知故障模式 #3 在对比方法里被判成未知的比例很高（准确率 0%–55%），AOSDGN 达到 87.5%；未知样本很少（测试时已知 200、未知 10）、训练样本减少到 100 个时，方法仍然有效。
- 超参数那一句被机翻弄乱了（"μ、β 和 δ 分别设置为 1、1 和 1.2"），请看英文原文。

## 2.6 创新点
作者声称的：
1. 提出并研究**开集域泛化故障诊断**这个场景；
2. 提出 **AOSDGN**：局部类聚类（三元组）+ 类别自适应决策边界；
3. 两个模块在训练中**互相受益**；
4. 在两个试验台上验证。

来源要分清：三元组损失、原型、自适应决策边界（Zhang 2021）都是已有技术；**新的是把它们放进"开集 + 域泛化"这个设定，并用类别自己的半径**。

## 2.7 局限（作者自己写的 + 我的看法）
- 作者承认：假设**已知故障有足够的样本**，未来要做小样本。
- 我的看法：域 = 工况（载荷/转速），在同一个试验台上；没有按"拆装"划分；训练用的是所有源域**全部带标签**的数据，不是 10% 标签；数据"应要求提供"，没有公开。

# 四、和你的课题的关系（有证据的才写）
1. **H-score 就是我们的 H**，可以直接说"沿用了 Zhao 2022 等开集工作使用的 H-score"。
2. **Peng 观察到的"未知故障和正常重叠"，在我们的数据上也出现**：新基线 B 里，未知窗口被判成健康的比例是 0.19、0.19、0.27（三折），被判成已知故障的只有 0.03、0.01、0.09（summary 里的"where do unknown windows go"）。
3. **Peng 的"造假未知"和我们做过的 E1 类似**：我们在信号空间用 VMD 造伪未知，加能量间隔损失，结果已知误判升到 0.40，变差了。差别是它在潜空间造样本，并把生成样本合并进"故障"一边来压紧正常类，而不是直接用能量间隔；**它们是否有效，在我们的数据上没有验证过**。
4. **Zhao 的设定和我们最接近**：如果把"一次安装"看成一个域，我们的训练安装就是多个源域，评估安装是没见过的目标域。差别：他们所有源域**全标签**、域是工况；我们只有 10% 标签、有大量无标签数据、域是安装。
5. **Zhao 说 EVT 和 LOF 这类基于密度的方法会失效，因为目标域的已知样本在源样本周围"解离"**。这和我们看到的现象一致：训练安装上已知性 AUROC 0.82，新安装上只有 0.67。
6. **Zhao 的"每个类自己的半径"和我们的保护阈值相关**：我们现在用一个阈值 τ，没有按类分开校准。这是一个**没有试过**的想法，不能说会有效。
7. 两篇都**没有按安装划分**，也都不是半监督，所以不能直接当作我们的对比基线，适合作为相关工作引用。
