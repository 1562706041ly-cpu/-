## 1. 一句话
源域有标签、目标域无标签，目标域还混有源域没见过的故障。MFCL 把它当成"**开集域自适应**"来做：用 DANN 对抗 + 源域原型把两个域对齐，用 SimCLR 式对比学习把目标域特征学好，再用一个 OSBP 式的对抗损失把"未知类"分出来，最后用 UniMatch 式的一致性损失做伪标签自训练（已知类、未知类分开训）。

## 2. 要解决什么问题
- **任务设定**：源域标签集 {1,…,C}，目标域标签集 {1,…,C, C+1,…,C'}，多出来的类全部合并成一个"未知类" C_u。开放度 = 1 − C/C'。
- **训练时能用目标域的无标签数据**（这一点和 Peng 2023、Zhao 2022 都不同，见第 10 节）。
- 作者指出已有开集 UDA 方法的两个问题：
  1. 判未知类靠**固定阈值**的辅助二分类器，或靠熵的经验规则；
  2. 没有充分利用**无标签目标数据本身的结构**。

## 3. 网络结构（图 4 + 代码）

| 部分 | 结构 | 输出 |
|---|---|---|
| 输入 | 一维振动信号，长 2048 | (1, 2048) |
| 特征提取器 f(·) | Conv1d(1→32, k=64)+BN+ReLU → Conv1d(32→32, k=16)+BN+ReLU → Conv1d(32→64, k=5)+BN+ReLU → Conv1d(64→64, k=5)+BN+ReLU → AdaptiveMaxPool1d(4) → Flatten | 64×4 = 256 维 |
| 瓶颈层（代码里属于特征部分） | Linear(256→256)+BN+ReLU | 256 维特征（对比、原型、对抗都用它） |
| 标签分类器 g(·) | Linear(256 → C+1) + Softmax | C 个已知类 + 1 个未知类 |
| 域判别器 d(·) | Linear(256→1024)+BN+ReLU → Linear(1024→1024)+BN+ReLU → Linear(1024→1)+Sigmoid | 源域 / 目标域的概率 |
| 两个梯度反转层 GRL | 一个在特征和域判别器之间，一个在特征和分类器之间（只用于分离对抗损失） | |

图 4 里分类器画成两层 (256→256→类别数)，代码里第一层其实是瓶颈层，算在特征里。卷积的步长图里没写，代码里是默认 1。

**整体只有一个 CNN 主干，三路输出**，参数共享。源域和目标域共用同一个 f 和 g。

## 4. 训练流程（图 3、算法 1）

框架分四个模块：

1. **DAM 数据增强模块**
   - 弱增强：归一化到 [0,1]（代码默认参数是 mean-std）。
   - 强增强：随机组合高斯噪声（按信噪比加）、时间遮挡、增益、平移、翻转、衰落、归一化。
   - 源域只用弱增强 x_s^w；目标域每个样本生成 3 个视图：弱 x_t^w、强 x_t^{s1}、强 x_t^{s2}。另外在 x_t^w 的特征上做 dropout(0.1)，得到"特征扰动"视图 x_t^{fp}。所以一个目标样本一共有 **4 个视图**，这就是标题里的"多视图"。
2. **SLM 监督学习模块**：源域交叉熵 L_sce。
3. **FCM 特征约束模块**（负责"对齐"）：
   - L_prt：目标特征向源域原型靠拢；
   - L_adv：DANN 域对抗；
   - L_tcl：目标域弱视图和强视图之间的对比学习。
4. **OSIM 开集识别模块**（负责"分离"）：
   - L_sal：分离对抗损失，把未知类和已知类分开；
   - L_ucl：未知感知一致性损失，按伪标签把目标样本分成已知 / 未知两组，分别做一致性训练。

**训练步骤**：
1. 前 5 个 epoch 热身：只用 L_sce + λ_tcl·L_tcl（代码里是 `epoch > 5` 才进主阶段，所以实际热身 6 个 epoch）。
2. 主阶段每个 batch：
   1. 用 EMA 更新源域原型 φ_s^c 和两组目标域原型；
   2. 用"分类器概率 × 原型权重"算出修正后的伪标签掩码 M；
   3. 用 M 判断每个目标样本是已知还是未知（指示函数 ξ）；
   4. 算总损失，一次反向传播更新 f、g、d。
3. **推理**：只把弱增强的测试样本送进 f 和 g，在 C+1 类里取 argmax。判成第 C+1 类就是"未知故障"。**不需要阈值**。

**总损失（式 16）**：
```
L_total = L_sce − λ_sal·L_sal + λ_ucl·L_ucl + λ_prt·L_prt − λ_adv·L_adv + λ_tcl·L_tcl
λ_sal = 1.0, λ_ucl = 1.0, λ_prt = 0.5, λ_adv = 0.5, λ_tcl = 0.5
```
L_sal 和 L_adv 前面的负号表示"对抗"。代码里两项都是直接加上去的，靠 GRL 实现符号翻转：
`loss = sce + esl + csl + 0.5*(prt + adv + ctl)`（esl 就是 L_sal，csl 就是 L_ucl）。

## 5. 损失函数逐个解释（带小例子）

### (1) L_sce：源域交叉熵（式 2）
```
L_sce = −1/n_s · Σ_i Σ_{c=1}^{C+1} y_{s,i,c} · log ŷ_{s,i,c}
```
- 普通的交叉熵。输出有 C+1 维，但源域没有未知类样本，所以第 C+1 维在这一项里**永远拿不到正标签**，只会被压低。未知类的概率全靠后面的 L_sal 和 L_ucl 抬起来。

### (2) L_prt：源域原型约束（式 3–6）
**原型** = 每个类的特征均值，按 batch 用 EMA 更新：
```
φ_s^c ← 0.5·φ_s^c + 0.5·(本 batch 里 c 类特征的均值)
```
- 例：旧原型 (1, 1)，本 batch 均值 (3, 1)，更新后是 (2, 1)。

目标样本对各原型的"归属概率"是距离的 softmax，损失是这个分布的**熵**：
```
p_c(x_t^w) = exp(−‖f(x_t^w) − φ_s^c‖) / Σ_c' exp(−‖f(x_t^w) − φ_s^c'‖)
L_prt = 平均[ −Σ_c p_c · log p_c ]
```
- 意思：让每个目标特征**明确地靠近某一个**源域原型。熵小表示归属明确，熵大表示夹在几个原型中间。
- 例：二维特征，3 个原型 (0,0)、(2,0)、(0,2)（代码用欧氏距离，没有平方）。
  - 目标特征 (0.2, 0.1)：距离 0.224 / 1.803 / 1.910，概率 0.719 / 0.148 / 0.133，熵 ≈ **0.789**。
  - 目标特征 (1, 1)：三个距离都是 1.414，概率都是 1/3，熵 = ln3 ≈ **1.099**（最大）。训练会把它推向某一个原型。
- **注意**：这一项只拉近、不管拉向哪个类，类别对不对它不负责。

### (3) L_adv：DANN 域对抗（式 7）
```
L_adv = −平均 log d(f(x_s^w)) − 平均 log(1 − d(f(x_t^w)))
```
- 域判别器 d 想分清源域（标 1）和目标域（标 0），特征提取器 f 通过 GRL 反过来想骗过 d，于是两个域的特征分布被拉到一起。
- 代码里是 `0.5*(BCE(源) + BCE(目标))`。
- 作者说之所以在原型约束之外还要它，是因为未知类在源域没有原型，L_prt 管不到，需要一个"全局"的对齐。

### (4) L_tcl：目标域多视图对比损失（式 8，基于 SimCLR）
- 正样本对：同一目标样本的弱视图 x^w 和强视图 x^{s1}。
- 负样本：batch 里其他样本的另一个视图，每个锚点 B−1 个，两个方向合计 2(B−1) 个。
- τ = 0.3。
```
论文式 8：L_tcl = −1/(2B) · Σ_{a∈{w,s1}} Σ_j log[ exp(f_a·f_b/τ) / Σ_{k≠j} exp(f_a·f_k⁻/τ) ]
```
- **论文和代码的差别**：
  - 论文分母**不含正样本**，代码（SupConLoss 不给标签时就是 SimCLR）的分母**包含正样本**。
  - 代码先对特征做 L2 归一化，论文没写。
  - 代码最后还乘了 τ/base_τ = 0.3/0.07 ≈ 4.29。
- 例（τ=0.3）：正样本相似度 0.8，两个负样本相似度 0.1 和 0.2。
  - 按论文式 8：−[0.8/0.3 − ln(e^{0.333}+e^{0.667})] ≈ **−1.46**，损失是负数，因为分母里没有正样本。
  - 按代码（分母含正样本）：≈ **0.209**，再乘 4.29 ≈ **0.895**。
  - 正样本相似度降到 0.3：代码版 ≈ **0.802**，变大，说明正样本对还不够近。
- 没有单独的投影头，直接在 256 维特征上做对比。

### (5) L_sal：分离对抗损失（式 9）
记 p_u = 判为未知类的概率，P_k = 所有已知类的概率之和，P_k + p_u = 1：
```
L_sal = −平均[ p_u · log P_k + P_k · log p_u ]
```
- 这个函数关于 p_u = 0.5 **对称**，在 0.5 处最小，往两头越来越大：

| p_u | 0.1 | 0.3 | 0.5 | 0.7 | 0.9 | 0.99 |
|---|---|---|---|---|---|---|
| L_sal | 2.083 | 0.950 | **0.693** | 0.950 | 2.083 | 4.559 |

- **对抗怎么起作用**（代码：`model(x_t_w, grad_reverse=True)`，GRL 加在特征和分类器之间）：
  - 分类器 g **最小化** L_sal：把每个目标样本的 p_u 往 0.5 推，也就是把决策边界放到"已知 / 未知各一半"的位置；
  - 特征提取器 f 通过 GRL **最大化** L_sal：把样本推离 0.5，要么明确是已知（p_u→0），要么明确是未知（p_u→1）。
- 这和 **OSBP**（Saito 2018）的思路几乎一样。OSBP 是让分类器把 p_u 推向阈值 t=0.5、生成器推离 t。区别是 OSBP 用 BCE(p_u, t)，这里用的是 P_k 和 p_u 的"交叉"形式。所以作者说的"无阈值"，实际上 **0.5 这个分界是被损失函数的形状隐含规定了**，只是不用手动设一个判别阈值。
- **注意**：
  - 论文算法 1 里 θ_f 和 θ_g 的更新式中 L_sal 前**都是负号**，按这个写法 f 和 g 都在最大化，就没有对抗了。代码里是 g 最小化、f 最大化，**以代码为准**。
  - 论文 3.4.1 节用"未知类熵高、已知类熵低"来解释动机，但贡献 (2) 又说它解决了"依赖熵经验规则"的问题，这两处说法有点矛盾。

### (6) L_ucl：未知感知一致性损失（式 1、10–15，基于 UniMatch）

**第一步：原版 UniMatch 一致性（式 1）**。用弱视图的预测当伪标签 ŷ^w，要求另外三个视图预测一致：
```
L = μ·CE(ŷ^w, p(x^{fp})) + μ/2·[CE(ŷ^w, p(x^{s1})) + CE(ŷ^w, p(x^{s2}))]，μ = 0.5
```
即权重 0.5（特征扰动视图）+ 0.25 + 0.25（两个强视图）。
- 例：伪标签是第 2 类，三个视图对第 2 类的概率分别是 0.7、0.5、0.4：0.5×0.357 + 0.25×(0.693+0.916) ≈ **0.581**。

**第二步：用目标域原型修正伪标签（式 10–13）**。
- 目标域也按伪标签建 C+1 个原型（**包括未知类**），同样用 EMA 更新。
- 每个目标样本到各目标原型的距离做 softmax，得到权重 ω。
- 修正后的类别 = argmax(ω × 分类器输出)。
- 例：分类器给出（类1 0.45，类2 0.40，未知 0.15），原型权重 ω =（0.2，0.7，0.1）。乘积是（0.09，0.28，0.015），伪标签从类 1 **改成类 2**。意思是分类器拿不准时，用"它离哪个簇中心近"来纠正。

**第三步：已知 / 未知分开训（式 14、15）**。
- 修正后判为已知类（ξ=1）的样本：用 ŷ^w 当标签做第一步的一致性损失，除以本 batch 已知样本数（γ₁B）；
- 判为未知类（ξ=0）的样本：**直接把标签设成 C_u**，做同样的一致性损失，除以未知样本数（γ₂B）；
- 这个判断用两套掩码做两遍：M^w 来自弱视图原型，M^{s1} 来自强视图原型（a ∈ {w, s1}），结果相加。
- 意义：原版 UniMatch 是闭集方法，不能让未知样本去拟合某个已知类的伪标签。这里先分组，再让未知样本**一致地输出"未知"**。这是这篇文章里**改动最多、最有自己东西的一项**。

**论文和代码的差别（以代码为准）**：
- 论文式 10 说目标原型来自强视图 s1、s2；代码里一组来自弱视图特征，一组来自 s1 视图特征，距离都是用弱视图特征算。
- 代码用**原始 logits**（不是概率）去乘原型权重。logits 可能是负数，乘权重的效果和论文写的"概率 × 权重"不完全一样。
- 代码先对三个视图的输出做了 softmax，又把结果送进 `F.cross_entropy`（它内部还会再做一次 log_softmax），相当于做了两次 softmax，梯度会变弱。如果你要复现或借用这一项，建议改成直接传 logits。

## 6. 创新点：主要是一个框架加损失函数吗？

**你的理解基本对。** 这篇的贡献主要是"一个组合框架 + 两个面向开集改造的损失"，网络结构本身没有创新（就是一个 4 层一维 CNN，和对比方法完全一样）。

作者列了 3 条贡献，对照来源看：

| 作者声称的贡献 | 用到的组件 | 来源 | 新东西有多少 |
|---|---|---|---|
| (1) 多视图特征一致性学习**框架** | 源域原型约束 L_prt、DANN 对抗 L_adv、SimCLR 对比 L_tcl | 原型熵约束是常见做法；DANN（Ganin 2015）；SimCLR（Chen 2020） | 各部件都是现成的，**新的是组合方式**：把它们放进开集 UDA，并且对比只在目标域的多视图上做 |
| (2) **无阈值**的分离对抗机制 | L_sal | 思路来自 OSBP（Saito 2018） | 损失形式（P_k 和 p_u 的交叉项）有变化，本质还是 OSBP 式的边界对抗 |
| (3) **未知感知一致性**学习 | L_ucl + 目标原型修正伪标签 | UniMatch（Yang 2023，原本是半监督语义分割） | **改动最多**：把闭集一致性改成"已知 / 未知分组"的一致性，并用目标原型给伪标签去噪 |

**写论文引用时可以这样概括**：MFCL 的创新集中在**训练目标的设计**上。一方面把多视图对比学习和 UniMatch 式一致性正则引入开集域自适应故障诊断；另一方面提出未知感知的一致性损失，用目标域原型修正伪标签，并对已知 / 未知样本分别施加一致性约束。

**消融实验能看出哪几项真正有用**（表 5，SDUST 8 个任务的平均 HOS，完整模型 91.83%）：

| 去掉的项 | 平均 HOS | 下降 |
|---|---|---|
| L_sal | 无法识别未知类（表里记为"/"） | — |
| L_ucl | 81.30% | **10.53** |
| L_tcl | 79.97% | **11.86** |
| L_prt | 88.69% | 3.14 |
| L_adv | 90.50% | 1.33 |

- 作用最大的是 **对比学习 L_tcl** 和 **一致性 L_ucl**；DANN 对抗只贡献 1.33 个点。
- L_sal 是"能不能识别未知类"的开关，因为它是唯一把第 C+1 类概率抬起来的项（L_ucl 依赖它先产生未知伪标签）。

## 7. 实验设置和主要结果

**数据集**（每个健康状态 320 个训练样本、80 个测试样本，每个样本 2048 点）：
- **SDUST**（山东科技大学轴承）：2000 rpm，20 N / 40 N 两种负载；10 类 = 正常 + 内圈 / 外圈 / 滚动体 × 3 个故障尺寸（0.2、0.4、0.6 mm）。
- **BJTU-RAO**（北京交通大学转向架）：20 Hz / 0 kN 和 60 Hz / −10 kN；5 类 = 正常、内圈、外圈、滚动体、保持架。

**任务**：16 个迁移任务（S1–S8、B1–B8），开放度 0.1–0.8，见表 2。

**训练设置**：
- SGD（动量 0.9），学习率 0.001 加退火，75 个 epoch，batch 32；
- RTX 4070；每个任务重复 5 次，报均值 ± 标准差。

**对比方法**：
- Source-only 和闭集 UDA 方法 DANN；
- 7 个开集 UDA 方法：OSBP、DAOSDA（文献 [35]，Zhao 和 Shen 的双对抗方法，和笔记 01 的 Zhao 2022 是同一作者，但不是同一篇）、ANNA、MAOSDAN、RRDA+shot、COSDA、PUMCL。

**评价指标**：
- OS：所有类的平均准确率；
- KNO：已知类平均准确率；
- UNK：未知类准确率；
- **HOS**：KNO 和 UNK 的调和平均，作者认为它是主指标。

**主要结果**（平均值）：

| 数据集 | 指标 | MFCL | 第二名（PUMCL） | 差距 |
|---|---|---|---|---|
| SDUST | OS | 92.88% | 88.25% | +4.63 |
| SDUST | HOS | 91.83% | 86.84% | +4.99 |
| BJTU-RAO | OS | 96.16% | 94.64% | +1.52 |
| BJTU-RAO | HOS | 96.51% | 94.18% | +2.33 |

- 两个数据集上，OS 和 HOS 各在 8 个任务中的 5 个拿到最好。
- 计算开销（表 6）：SDUST 训练 1370 s，所有方法里最慢；DANN 281 s，OSBP 254 s。推理时间（整个测试集）都不超过 0.12 s，没有差别。

## 8. 局限性和需要注意的地方

1. **只做了轴承、只做了两个工况之间的迁移**，每个数据集只有一对工况来回迁移。
2. **方差很大**：比如 S4 的 HOS 是 95.47 ± 10.02，S7 的 KNO 是 94.50 ± 12.30。一些任务上和对比方法的差距小于标准差。
3. **开放度小时已知类精度下降**：S1 的 KNO 是 81.50%，DANN 是 98.31%。作者自己也承认，开集方法和闭集方法在已知类上还有差距。
4. **未知类只当成一个类**，不区分具体是哪种新故障。
5. **训练要用目标域的无标签数据**，部署前必须先采到新工况的数据。
6. **评价指标的公式写法和代码不一致**：式 18、19 写的是 TP/(TP+FP)（这是精确率），代码 `compute_h_score` 算的是每类的召回率再取平均（这是开集 UDA 常用的定义）。以代码为准。
7. **模型选择可能偏乐观**：代码每个 epoch 都在目标域测试集上算 H-score，最后打印 `best_h_score`（所有 epoch 里最好的一次）。如果论文报的是这个值，相当于用测试集挑了模型。论文没写清楚报的是最后一个 epoch 还是最好的一个，**这点我不能确定**。
8. **一些笔误**：
   - 4.5.1 节解释图 11(b) 时把 λ_adv 写成了 λ_prt；
   - 结论里写"2 个闭集 + 4 个开集方法"，实际实验是 1 个闭集（DANN）+ Source-only + 7 个开集；
   - 结论里写 "OA"，正文用的是 "OS"；
   - 算法 1 里写的 L_cls 就是式 16 的 L_sce。
9. **代码和论文有出入**：
   - 原型在每个 epoch 开始时用随机数初始化，不是论文式 3 说的类均值；
   - 源域原型矩阵也有第 C+1 行（未知类），但源域没有未知样本，这一行一直是随机值；
   - 其余出入见第 5 节各小节。
