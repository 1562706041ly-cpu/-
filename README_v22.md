# v22：已知类保护改用"距离融合"（D1 + D2）

## 做了什么
- **D1 距离融合**：已知性分数 = 0.5 × z(深度特征 kNN 距离) + 0.5 × z(人工特征 kNN 距离)。人工特征共 58 维/通道：时域统计 6、频带能量 32、谱形状 3、包络谱 17。
- **D2 安装感知校准**：两个 z 分数都用"已标注窗口只和**其他安装**的窗口比较"的分布来标定；阈值 τ 取这个融合分数的 40% 分位数。只用已知类的安装编号。
- 人工特征的参考窗口**只用已标注窗口**：伪已知窗口不纯（有的划分只有 69% 真是已知），混进去后人工特征的 AUROC 从 0.89 掉到 0.53。

## 沙箱结果（种子 0，只是离线筛选，不是最终结论）
- 在 v20 训练好的模型上，新安装的已知/未知判别 AUROC（9 个划分平均）：当前 K 0.666；深度 kNN 0.689；人工特征 kNN 0.628；深度+人工融合 0.743（全部特征）/ 0.782（只用频带能量）。
- 注意：这一步没有事先写判断标准，且比较了约 12 个变体，0.782 是在同样的评估安装上挑出来的，偏乐观。
- 人工特征在不同划分上很不稳定（0.18 到 0.89）；时域统计量和包络谱特征在新安装上接近或低于随机（0.36 / 0.49）。
