## 方法 A 做了什么
- 判为已知类的窗口（已标注，或已知性 K ≥ 0.5），把它的 VMD 模态对数能量剖面，往**同类另一次已标注安装**的剖面移动：移动量 = λ·(源安装剖面 − 当前安装剖面)，λ = 样本预算 κ(K,R) × U(0,1)。
- 剖面只用已标注窗口计算；当前所属安装用最近的剖面来估计；其余窗口仍用原来的随机扰动。
- 和随机扰动的区别：混合用的是**真实安装的、模态之间相关的剖面**，而不是每个模态独立的随机抖动。
- **局限**：每个已知类训练时只有 2 个安装（软脚只有 1 个），所以"用距离挑选源安装"无处可选，没法检验；距离只通过 K 起作用。
