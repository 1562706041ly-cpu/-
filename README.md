# 第三章研究说明:开放环境下的少标签故障诊断与增强设计

这份说明给第一次看这项工作的人(导师、同学),讲清四件事:研究什么问题、为什么做、做了什么、目前结论。详细数字和原始结果见文末链接。

## 1. 研究问题

实际设备上采到的振动数据有三个特点:
- **标签很少**:只有一小部分数据被人工标注(实验里是已知类训练窗口的 10%)。
- **有新故障**:未标注数据里既有已知故障,也有训练时从没见过的**未知故障**。
- **设备有差异**:同一种故障装在不同设备(安装)上,信号也不一样。

任务是**广义类别发现(GCD)**:模型要把已知故障分对,同时把未知故障找出来,并把不同的未知故障分开。

第三章研究的是其中一个环节:**怎样设计数据增强**,让模型在少标签、跨安装的条件下学到更好的特征。

## 2. 为什么做

- 对比学习依赖"同一样本的两个增强视图应该相似"。增强太弱学不到东西,太强会破坏故障信息。
- 已知样本和未知样本、可靠样本和不可靠样本,也许应该用不同强度的增强。
- 原设想是:先估计每个样本"像不像已知类"(已知性 K)和"这个判断稳不稳"(可靠度 R),再据此分配 VMD 模态扰动的强度,并用保真检查防止扰动过大。

## 3. 做了什么

**数据**:Bruinsma 电动机驱动离心泵,Motor-2、100% 转速,4 个振动通道,17 个安装。按安装留出做 3 个组合 × 3 折:测试用的安装在训练时完全没出现过。75% 转速的数据封存,没有打开,留作以后一次性测试。

**基础方法**:4 通道对数谱 → 1-D CNN 编码器 → 对比学习 + 少量标签监督 → 半监督 k-means 聚类(未知类数预设为 3)→ 已知类保护阈值。

**做法上的约束**:每个实验的判断标准都在运行**之前**写好并推送到 GitHub(预注册),跑完后不改标准;负结果照实记录。

**实验内容**(全部以不做第三章增强的 Bg4 为基线):
1. 已知性 K 的三种算法(最近邻、距离能量、能量门控融合)
2. 第三章自适应 VMD 增强整体效果
3. 其他变体:能量决定扰动方向、安装混合、手工特征融合
4. 扰动剂量(gain 1、2、4)与"按 K、R 分配"对"随机分配"
5. 机制诊断(不训练,只看固定模型):扰动有多大、预算是否传到信号和特征、特征稳定性检查、扰动是否削弱未知类之间的可分性、通道与频带对应
6. 离开 VMD 后的新尝试:按频带的增益扰动,比较"各通道独立"与"跨通道协调"

## 4. 目前结论

**有效的部分**(基础方法的改进,不属于第三章增强):
- 4 通道对数谱输入:H 从 0.441 提高到 0.646。
- 留一安装校准的已知类保护:已知误判为未知从 0.304 降到 0.177,H 0.650;代价是未知召回从 0.744 降到 0.626,未知聚类准确率从 0.578 降到 0.483。

**第三章增强的部分:在当前数据上没有观察到收益。**
- K 的三种算法,最终 H 没有可测差别(例如最近邻对门控融合 +0.002,区间 [−0.006, +0.008])。
- 自适应 VMD 增强相对 Bg4 略低(事后分析,−0.009)。
- 加大剂量、按 K/R 分配预算,都没有显示收益;自适应与随机分配的差是 −0.001。
- 机制诊断显示预算确实传到了扰动和特征,但这没有转化为端到端收益。
- 频带协调增益相对 Bg4 为 +0.006,区间 [−0.016, +0.028],没有达到预设标准,这条线已按规则停止。

**怎么理解**:
- 第三章目前是"一套提出并完成初步验证的候选增强机制,在当前离心泵实验中端到端收益未得到支持"。不能写成已验证有效的创新。
- 多组对照共用同一批划分和设置,不是相互独立的证据。准确的说法是"多组对照都没有观察到稳定收益",不是"证明无效"。
- 可以主张的可能是:按安装留出的评估方式、留一安装保护校准及其权衡、以及一套系统的机制分析。它们能否算作创新,还要和已有工作比较。

**限制**:
- 这是离心泵数据,不是柱塞泵;只有一个工况。
- 9 个划分之间共享安装,部分筛查只有一个随机种子,区间较宽。
- 100% 转速数据已多次用于方法开发,上面的结果属于开发阶段评估,不是在未见数据上的确认。

## 5. 需要讨论的问题

1. 第三章如何重新定位:以机制分析和负结果为主,还是提出新的、可检验的假设?
2. 是否以及何时用封存的 75% 转速数据做一次性测试(它和 100% 存在工况差异)。
3. 是否能获得目标设备(柱塞泵)的数据做最终验证。
