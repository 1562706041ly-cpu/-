# 设计文档 v2：固定 ETF 框架下的跨域广义类别发现（液压 / 离心泵振动）

状态：**框架已确定，损失创新待补，还没有预注册**。本文的阈值、权重都是建议值。按原来的规则：先推送预注册文件，再写代码、跑实验。

v1 → v2 的主要变化：编码器选择理由更正（神经塌缩不依赖残差结构）；第三章模块改为"可靠度感知的强视图生成器"；新增输入表示对照（一维谱 vs 时频图）；基线加入 TRAILER、NCDLR；文献定位按核对结果修改。

## 0. 一句话
先用 BYOL 加固定 ETF 预训练编码器，并给未知类预留位置；再把目标域中可靠的已知样本拉向对应的已知原型，把可靠的未知样本分配到 3 个固定未知槽。最终在新设备上把已知故障分对，并把未知故障按类别分开。

## 1. 问题设定
| 项目 | 内容 |
|---|---|
| 源域 S | 训练安装：已知类窗口的 10% 有标签，其余无标签 |
| 目标域 T | 新设备（留出安装）：全部无标签，含已知故障和未知故障，**训练时可用** |
| 未知类数 | 预设 3，论文中写明为给定条件；另做一次估计实验（第 9 节） |
| 输出 | 目标域上的已知类别，以及未知 1 / 2 / 3 |

- 目标域按"测量记录 =（安装, 测量编号）"拆成两半：T_adapt 参与训练，T_eval 只用于评估。同一条记录的窗口不能两边都有；每个类在两边都至少有 1 条记录，做不到的划分单独标注。
- 未知类标签只用于评估和事后诊断，不进入训练和调参。
- 划分沿用 3 个组合 × 3 折；75% 转速数据继续封存。

## 2. 网络
- **编码器 f**：主线用现有一维 CNN，和 Bg4 保持一致，便于归因。一维 ResNet 作为单独对照（E1）。
  - 依据：神经塌缩在 VGG（普通 CNN）、ResNet、DenseNet 上都观察到（Papyan 2020）；Layer-Peeled Model 的结论与具体结构无关（Fang 2021）。而且本方案是直接固定 ETF，不依赖网络自然塌缩（TRAILER 也指出自然塌缩在不理想条件下容易失败）。
- **BYOL 分支**：投影 MLP（→256→128）、预测 MLP（128→256→128）、EMA 目标网络（τ_ema = 0.99）。
- **ETF 分支 g**：MLP（→256→d），L2 归一化得到 z，d = 128。
- 两个分支互相独立，都接在编码器输出后面。

## 3. 固定 ETF
- K = C + 3，C 为已知类数，后 3 个为未知槽 u1–u3。
- M = sqrt(K/(K−1)) · U · (I_K − 11ᵀ/K)，U 为 d×K 随机列正交矩阵，每列 L2 归一化，两两余弦为 −1/(K−1)。种子固定为 0。M 不训练。
- 分数：s_k(z) = cos(z, m_k) / τ，τ = 0.1。

## 4. 训练

### 阶段 ① 预训练（第 0–300 步）
目的：(1) 不依赖伪标签先学出可用特征；(2) 给第二阶段的门控和伪标签打底，避免确认偏差；(3) 已知类先占好原型位置，未知槽的空间提前留出。
- L_byol：源域 + T_adapt 的全部窗口。
- L_src：源域有标签样本，对全部 K 个原型做交叉熵（被拉向自己的已知原型，同时被推离其他已知原型和未知槽）。类均衡采样。
- L = L_byol + L_src。

### 阶段 ② 自适应（第 300–1500 步）
伪标签每 100 步刷新一次。

**(a) 门控**：分数 k(x) = max_{c≤C} cos(z, m_c)（ETF 最大余弦，依据 ProtoGCD 的 MLS）。阈值只用源域标签，按留一安装方式校准：t_hi / t_lo = 已知窗口分数的 5% / 1% 分位数。
| 组 | 条件 | 去向 |
|---|---|---|
| 可靠已知 | k ≥ t_hi，且弱 / 强视图的已知类 argmax 一致 | L_ta |
| 可靠未知 | k < t_lo，且强视图也 < t_lo | L_unk |
| 不确定 | 其余 | 只参与 L_byol |

**(b) 未知分配**：3 个固定未知槽就是中心，不做 k-means、不需要匹配器。弱视图按余弦分配，用放宽的均衡分配（依据 TRAILER、NCDLR）：每个槽最低占比约 10%，不要求严格均分。

**(c) 损失**
| 损失 | 作用 | 来源 |
|---|---|---|
| L_src | 源域已知类拉向已知原型 | TRAILER / NC-GCD |
| L_ta | 可靠已知目标样本：强视图拟合弱视图的已知类伪标签 | FixMatch；按可靠度选择性对齐参考 Zhang 2021、STA |
| L_unk | 可靠未知目标样本：强视图拟合分配到的未知槽，按槽位类均衡 | TRAILER、NCDLR、DeepCluster |
| L_byol | 保留，小权重 | BYOL |
| **L_new（待定）** | **损失创新的位置**，例如相对间隔、拒绝耦合加权，放在 L_unk 中或与其并列 | 待检索确认新颖性 |

L = L_src + β(t)·(L_ta + L_unk) + 0.1·L_byol，β 在第 300–500 步从 0 线性升到 1。

### 第三章模块：可靠度感知的强视图生成器
- L_ta、L_unk、L_byol 的强视图由第三章的 VMD 扰动产生，保真检查不通过的视图退回弱增强。
- 扰动强度按门控分组分配：可靠已知较强；可靠未知中等，避免破坏区分未知故障的成分；不确定较弱或只用通用增强。
- 必须配对照：第三章强视图 vs 通用强增强（噪声、时间遮挡、平移）。第三章曾测得"自适应 vs 随机分配"差值为 −0.001，若这里仍无差别，如实报告。
- VMD 分解在沙箱里预先算好，本地只做 GPU 训练。

## 5. 推理
1. 测试窗口只做弱处理，得到 z。
2. k(x) ≥ t_guard 判为已知，输出 argmax 已知类；t_guard 在新特征上按留一安装保护规则重新校准。
3. 否则分给最近的未知槽，得到未知 1 / 2 / 3。
4. 对照：对被拒绝的样本另做 k-means（k = 3），用编码器输出或 ETF 分支 z，预注册时写明用哪一层。

## 6. 指标
- 主指标：H；未知聚类准确率（匈牙利匹配，被判为已知的未知窗口算错）。参考：带保护的 Bg4 为 0.483（旧设定，新设定需重跑）。
- 次要：已知误判为未知的比例、NMI、各未知类召回。
- 机制诊断：未知类中心之间的平均余弦；NC1（类内 / 类间方差）在源域训练集和 T_eval 上分别计算；每次刷新时各槽人数。

## 7. 实验
| 编号 | 配置 | 回答的问题 |
|---|---|---|
| E0 | Bg4，新设定，不用 T_adapt | 原始基线 |
| E0′ | Bg4，对比学习加入 T_adapt | 看到目标无标签数据本身的作用 |
| E1a | E0′，编码器换一维 ResNet | 编码器 |
| E1b | E0′，输入换 4 通道 STFT/CWT 时频图 + 二维网络 | 输入表示（不用 1024→32×32 直接重排） |
| E2 | E0′ + 阶段 ①（BYOL + 固定 ETF） | 固定 ETF 预训练 |
| E2′ | E2，原型可学习 | "固定"是否关键 |
| E3 | E2 + 阶段 ②，所有未知只用 1 个槽 | 目标对齐 |
| **E4** | E2 + 阶段 ②，3 个未知槽 | **主方法** |
| E4′ | E4，去掉门控 | 门控 |
| E4″ | E4，强视图换成通用增强 | 第三章模块 |
| E5 | E4 + L_new | 损失创新（待定） |

**基线**：Bg4；GCD 式（对比学习 + 半监督 k-means，Vaze 2022）；TRAILER；NCDLR；OVANet + 对拒绝样本 k-means。TRAILER、NCDLR 需移植到一维输入。

E1a、E1b 的结果决定后续用哪种编码器和输入，规则写进预注册。

## 8. 超参数选取
- 只在源域上做留一安装验证（留出的训练安装当临时目标，它的标签只用于选参），在小网格内选取，然后冻结写入预注册。
- 正式在目标安装上跑之后不再调。敏感性分析只作描述。

## 9. 未知类数
- 主结果预设 3。
- 补充：阶段 ① 结束后，按 GCD 3.2 节的方法估计 K（全部数据做 k-means，只在源域有标签样本上算准确率，取最大值），并报告目标被拒绝样本上的轮廓系数。估不准则如实写为方法的限制。

## 11. 风险
1. 未知类数预设为 3，设错会硬拆或硬合并簇。
2. 伪标签确认偏差：门控、最低槽占比、每次刷新的日志就是为此准备的。
3. 目标域只用一半记录评估，区间更宽。
4. 100% 转速数据已多次用于开发，结果属于开发阶段证据。
5. 基线移植可能引入实现差异，需要在源码层面核对。
