# 设计草案 v1：带固定 ETF 预训练的跨安装广义类别发现

状态：**草案，还没有预注册**。这里写的阈值、权重和判定标准都是建议值，你确认或修改之后，再按原来的规则推送预注册文件，然后才写代码、跑实验。

## 0. 一句话
先用 BYOL 加固定 ETF 预训练编码器，并给未知类预留位置；再把可靠的目标安装样本按伪标签拉向同一组固定 ETF 原型。这样源域和目标域按类对齐，3 个未知类也各占一个原型，彼此分开。

## 1. 问题设定（和第三章不同）
| 项目 | 第三章（域泛化） | 本设计（域自适应） |
|---|---|---|
| 训练时能否用留出安装的数据 | 不能 | **能，只用无标签窗口** |
| 标签 | 训练安装已知类窗口的 10% | 相同 |
| 未知类数 | 预设 3 | 预设 3 |
| 评估 | 留出安装的全部窗口 | 留出安装中**另一半测量记录**的窗口 |

- **源域** S：训练安装，包括有标签窗口和无标签窗口。
- **目标域** T：留出安装，按"测量记录 = (安装, 测量编号)"一分为二：
  - T_adapt：训练时作为无标签数据使用；
  - T_eval：只用于评估。
  - 同一条记录切出的窗口不能跨两边。每个类在两边都至少要有 1 条记录，做不到的划分要记录下来，单独标注。
- 未知类标签**只用于评估和事后诊断**，不进入训练和调参。
- 划分沿用原来的 3 个组合 × 3 折。75% 转速数据继续封存。
- **基线也要在新设定下重跑**：Bg4 用 T_eval 评估，并且"带 T_adapt 做自监督"和"不带"两种都要跑。

## 2. 网络
- **编码器 f**：先沿用现有一维 CNN；一维 ResNet 作为单独的一项比较（见第 7 节 E1），不和 ETF 同时引入。
  - 一维 ResNet 建议：输入 4 通道对数谱；4 个阶段，通道数 32、64、128、256，每个阶段 2 个残差块；全局平均池化。
- **BYOL 分支**：投影 MLP（→256→128）和预测 MLP（128→256→128）；目标网络用 EMA 更新，τ_ema = 0.99。
- **ETF 分支 g**：MLP（→256→d），输出做 L2 归一化，得到 z。d = 128。
- 两个分支都接在编码器输出后面，**互相独立**。

## 3. 固定 ETF
- 类别总数 K = C + 3，C 是已知类数，后 3 个位置留给未知类。
- 构造方法：
  - M = sqrt(K/(K−1)) · U · (I_K − 11ᵀ/K)，U 是 d×K 的随机列正交矩阵；
  - 每一列做 L2 归一化，两两余弦都等于 −1/(K−1)。
- 随机种子固定为 0 并记录。M 存成 buffer，**不参与训练**。
- 位置分配：第 0…C−1 列对应已知类，第 C…C+2 列对应未知槽 u1、u2、u3。
  - ETF 是对称的，在训练开始前固定的话，具体哪一列分给哪一类没有影响，所以不需要额外匹配。
- 预测分数：logit_k = cos(z, m_k) / τ，τ = 0.1。

```python
def make_etf(d, K, seed=0):
    g = torch.Generator().manual_seed(seed)
    U, _ = torch.linalg.qr(torch.randn(d, K, generator=g))
    M = (K / (K - 1)) ** 0.5 * U @ (torch.eye(K) - torch.ones(K, K) / K)
    return F.normalize(M, dim=0)   # d×K
```

## 4. 训练流程（总共 1500 步，和现有实验一致）

### 阶段 P1：预训练（第 0～300 步）
- **L_byol**：源域和 T_adapt 的全部窗口，弱视图和强视图各一个，对称计算：
  2 − 2·cos(q(z₁), sg(z₂′)) + 2 − 2·cos(q(z₂), sg(z₁′))。
- **L_etf_s**：有标签的源域窗口，**对全部 K 列**做交叉熵。
  - 样本被拉向自己的已知原型，同时被推离其他已知原型和 3 个未知槽，未知槽的位置因此被预留下来。
  - 按类均衡采样，或按类加权，对应 Fang 2021 的少数类塌缩问题。
- 总损失：L_P1 = L_byol + α·L_etf_s，α = 1。
- 这一阶段无标签样本**不**对齐 ETF。

### 阶段 P2：自适应（第 300～1500 步）
每 100 步更新一次伪标签（"刷新"）。刷新之间伪标签不变。

**(a) 打分**（用弱视图，不回传梯度）
- 已知性 k(x) = max_{c<C} cos(z, m_c)。
- 一致性：弱视图和强视图在已知类上的 argmax 相同，记为 agree(x) = 1。

**(b) 门控阈值**（只用源域有标签数据，留一安装校准，沿用现有保护机制的做法）
- 对每个训练安装，用其余安装训练时的分数分布，取它的有标签已知窗口的 k 值。
- t_hi = 这些 k 值的 5% 分位数，t_lo = 1% 分位数。
- 按规则把每个样本分到三组：

| 组 | 条件 | 伪标签 |
|---|---|---|
| 可靠已知 | k ≥ t_hi 且 agree = 1 | argmax 已知类 |
| 可靠未知 | k < t_lo，并且强视图的 k 也 < t_lo | 未知槽（见下） |
| 不确定 | 其余 | 不参与 ETF 项 |

**(c) 未知槽分配（时间一致的匹配，参考 NC-GCD 的 SCM）**
1. 对可靠未知样本的 z 做 k-means，k = 3，初始化取上一轮的中心。
2. **第一次刷新**：用匈牙利算法把 3 个簇中心匹配到 3 个未知槽，代价 = −cos(中心, m_u)。
3. **之后每次刷新**：先把新簇和上一轮的簇按中心余弦做匈牙利匹配，**继承**上一轮的槽位；只有新匹配的余弦低于 0.5 时，才改用和 ETF 槽位的匹配，并记录这次重新分配。
4. 某个簇少于 max(20, 可靠未知数的 5%) 个样本时，这一轮该簇不参与 L_etf_t。
5. 每次刷新都记录：各组人数、各簇人数、槽位是否变化。如果评估时可以使用真实标签做诊断，还要记录可靠组的伪标签准确率（只做诊断，不用于调参）。

**(d) 损失**
- **L_etf_t**：可靠已知和可靠未知样本，用**强视图**的 logits 拟合弱视图得到的伪标签，交叉熵；每个伪类权重 = 1 / 该类样本数（类均衡）。
- **L_etf_s**：继续保留。
- **L_byol**：保留，权重降低。
- 总损失：L_P2 = L_etf_s + β(t)·L_etf_t + γ·L_byol，β 在第 300～500 步内从 0 线性升到 1，γ = 0.1。

**(e) 不加 DANN**
- 源域和目标域同类样本被拉向同一个固定原型，相当于已经在做按类对齐。
- 整体对齐（DANN）只作为一项消融（E5），而且只对可靠已知样本做。

## 5. 推理
1. 测试窗口只做弱处理，得到 z，计算对 K 个原型的余弦。
2. k(x) ≥ t_guard 判为已知，输出 argmax 已知类。
   - t_guard 按现有的留一安装保护校准规则，在**新特征**上重新计算，不沿用旧值。
3. 否则判为未知，类别 = argmax_{u1,u2,u3} cos(z, m_u)。
   - 比较项：对被拒绝的样本另外做 k-means（k = 3），看两种分配哪个好，作为描述性结果。

## 6. 指标
- 主指标：**H**（已知准确率和未知召回的调和平均），以及**未知聚类准确率**（匈牙利匹配，被判为已知的未知窗口算错）。
- 次要指标：已知误判为未知的比例、NMI。
- 机制诊断（描述性）：
  - 在源域训练集和 T_eval 上分别计算 NC1 = Tr(Σ_W Σ_B⁺)/K；
  - NC2 = 类中心两两余弦与 −1/(K−1) 的平均绝对差；
  - 未知类之间的平均余弦。

## 7. 实验设计
全部配置都在新设定下跑，9 个划分 × 3 个种子。

| 编号 | 配置 | 回答的问题 |
|---|---|---|
| E0 | Bg4，编码器只用源域训练 | 新设定下的原始基线 |
| E0′ | Bg4，自监督部分加入 T_adapt | "看到目标无标签数据"本身带来多少收益 |
| E1 | E0′，编码器换成一维 ResNet | 换编码器有没有用 |
| E2 | E0′ + P1（BYOL + 固定 ETF，只用有标签样本） | 固定 ETF 预训练有没有用 |
| E2′ | E2，但原型可学习 | "固定"是不是关键 |
| E3 | E2 + P2，所有未知只用 1 个槽 | 目标对齐有没有用 |
| **E4** | E2 + P2，3 个未知槽 + 时间一致匹配 | **主方法** |
| E4′ | E4，去掉时间一致匹配（每次刷新都重新和 ETF 匹配） | 匹配机制有没有用 |
| E4″ | E4，去掉门控（全部目标样本都参与） | 门控有没有用 |
| E5 | E4 + 只对可靠已知样本做 DANN | 整体对齐还能不能再加分 |

E1 的结果决定后续配置用哪个编码器。这一步要在预注册里先写好规则，比如"E1 − E0′ 的 ΔH 平均值 > 0 且 ≥ 18/27 个运行更高，才换成 ResNet"。

## 8. 建议的判定标准（沿用现有规则，待你确认）
- **主比较 E4 − E0′**：平均 ΔH > 0，≥ 18/27 个配对运行更高，并且对 9 个划分做自助法（每个划分取 3 个种子的平均，10000 次）得到的 95% 区间下界 > −0.01。
- **创新点比较 E4 − E3**（3 个未知槽 vs 1 个）：未知聚类准确率的平均差 > 0，≥ 18/27 个运行更高；同时 H 不劣于 E3（区间下界 > −0.02）。
- 其余比较只作为描述，不做判定。

## 10. 风险
1. **未知类数预设为 3**：设错的话，多出的槽会把一个簇硬拆开，少了会硬合并。报告里要写明这是给定条件。
2. **伪标签确认偏差**：早期分错的簇会被越训越牢。门控、最小簇大小和每次刷新的日志就是为此准备的。
3. **目标域只剩一半记录评估**：区间会更宽。有的划分里某个类只有 1 条记录，要单独标注。
4. **类别不均衡**：未知类在 T_adapt 里样本可能很少，要靠类均衡权重处理。如果实验中仍然出现未知槽之间的余弦升高，就是少数类塌缩的迹象，这一项要记录。
5. **数据复用**：100% 转速数据已多次用于开发，这里的结果仍然只是开发阶段证据。

**可以主张的新东西**（需要先查一下有没有人做过"固定 ETF + 域自适应 + 故障诊断"）：
- 把固定 ETF 作为跨安装的**统一对齐目标**，替代 DANN 和可学习原型；
- 用**留一安装校准的门控**决定哪些目标样本参与对齐；
- 用**多个未知槽**配合时间一致匹配，在跨域条件下把不同的未知故障分开（E4 − E3 是直接证据）。
