# 论文上传区

把你读过的论文 PDF 上传到 `papers/` 文件夹里。

## 上传方法（网页）
1. 打开本分支（papers）页面，进入 `papers` 文件夹。
2. 点 **Add file → Upload files**，把 PDF 拖进去。
3. 点 **Commit changes**，注意提交到 **papers 分支**，不要提交到 main。

## 注意
- 网页上传每个文件最大 25 MB；超过的先压缩，或者告诉我。
- 文件名建议：`作者_年份_简称.pdf`，例如 `Sun_2022_kNN-OOD.pdf`。
- 扫描版 PDF（图片）我可能读不出文字；能复制文字的 PDF 最好。
- 如果某篇你只想让我看其中几页，在文件名里注明，或者在对话里告诉我页码。
