## 研究设定
- 振动故障诊断中的广义类别发现（GCD）。源域是训练安装，10% 已知类窗口有标签；目标域是新设备，全部无标签，含已知故障和多种未知故障，训练时可用。
- 目标：已知故障分对；未知故障**按类别分开**（预设 3 类），不能合成一个"未知"。
- 数据：Bruinsma 电动机驱动离心泵，Motor-2，100% 转速，4 通道。75% 转速封存。最终希望用柱塞泵验证。
- 用户不同意"跨安装无关约束"这一方向，不再讨论。

## 已确定的框架（详见设计文档 v2）
- 编码器：一维 CNN（和基线 Bg4 一致），一维 ResNet、时频图 + 二维网络作为对照。神经塌缩不依赖残差结构。
- 固定 ETF 原型：C 个已知 + 3 个未知槽，不训练。
- 阶段 ① 预训练：BYOL（两个域全部窗口）+ 源域有标签样本对 ETF 的交叉熵（未知槽位置预留）。
- 阶段 ② 自适应：门控（ETF 最大余弦，阈值用源域留一安装校准）分出可靠已知 / 可靠未知 / 不确定；L_ta 拉向已知原型，L_unk 用放宽均衡分配拉向未知槽（未知槽固定，不需要匹配器）。
- 第三章模块保留为"可靠度感知的强视图生成器"（VMD 扰动 + 保真检查，按门控分组分配强度），配通用增强对照。
- 推理：保护阈值判已知 / 未知，未知分给最近的未知槽。
- 基线：Bg4（新设定重跑）、GCD 式、TRAILER、NCDLR、OVANet + k-means。

## 损失创新：尚未确定（L_new 位置已预留）
文献核对结论：
- 固定 ETF + 新类原型 + Sinkhorn 均衡：TRAILER（CVPR 2024，10.1109/CVPR52733.2024.02177）已做。
- 固定 ETF + 不均衡新类 + 放宽最优传输：NCDLR（TMLR 2023，arXiv:2308.02989）已做。
- 未知样本远离已知类的间隔：Feng 2019（ICCV，10.1109/ICCV.2019.00808）已做（单个未知类、绝对间隔）。
- 按可靠度选择性对齐 / 伪标签分组：Zhang 2021（TII）、STA、MCDL 已做。

剩下的候选（都需要再检索新颖性）：
1. 相对间隔：未知样本对所属未知槽的余弦比对最近已知原型高出 δ（多未知槽 + 以所属槽为参照，区别于 Feng 2019）。
2. 拒绝耦合加权：未知槽交叉熵的权重取样本超出相对间隔的程度。
3. **伪标签修正后再纠正分类损失**（用户的新想法）：先修正伪标签，再用修正后的标签算 L_ta / L_unk。已有类似做法：MFCL（原型权重修正）、TRAILER（PU 头修正）、IOMatch / OSCL、ProtoGCD。可能的新点：用第三章保真检查（扰动后预测是否稳定）作为修正信息，或用历史一致性、近邻一致性。要注意确认偏差，并配"不修正 vs 修正"对照。
