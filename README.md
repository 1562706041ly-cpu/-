# 论文理解分支（paper-reading）

这个分支只放**论文解读笔记**，不放代码和数据。论文 PDF 仍然放在 `papers` 分支。

## 怎么用
1. 把要读的论文 PDF 上传到 `papers` 分支的 `papers/` 文件夹（方法见那个分支的 README）。
2. 在对话里告诉我：读哪一篇、想重点弄懂什么（例如"流程""公式推导""创新点""和我的方法有什么区别""能不能用在液压泵故障诊断上"）。
3. 我把解读写成一个 Markdown 文件，提交到本分支的 `notes/` 文件夹，并更新下面的 `论文清单.md`。
4. 你在网页上直接打开 `.md` 文件阅读，不需要下载。

## 每篇笔记的固定结构
1. 我读到了什么、没读到什么（图片里的公式、表格数字读不出来时会写明）
2. 一句话概括
3. 要解决什么问题
4. 方法流程（按步骤）
5. 关键公式：逐项解释，并配一个能手算的小例子
6. 创新点
7. 实验设置和主要结果（只写原文明确给出的数字）
8. 局限性
9. 和我的研究的关系（可借鉴什么、能怎么引用）
10. 不懂的地方 / 待核对

## 文件夹
- `notes/`：每篇（或每组）论文一个笔记文件，按编号排序。
- `论文清单.md`：所有论文的标题、期刊、DOI 和阅读状态。
