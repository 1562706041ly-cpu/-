v24p numeric and split check (2026-11-06). Original v24p results are kept unchanged; this is a separate record.
1) Stable sigmoid (scipy.special.expit) recompute on the same 27 warm-up models: every metric identical to the original run (max abs difference 0.0).
   The earlier exp-overflow warnings only produced inf -> 0, the correct limit. Saturated scores (q < 1e-6 or > 1-1e-6): mean 8.0 % of scored windows, max 44.1 % in one model. Ties at 0/1 exist and are part of the calibration, not an error.
2) Split composition (C1..C3, fold 1, seed 0; known labels = [0,1] in every combo; 5 classes):
   held-out set S_V: 800 windows, 160 per class, 60 % unknown; 5 installations. Training S_U: ~1376 unlabelled windows, 58-69 % unknown, 9-10 installations. Labelled: 64 windows (32 per known class; 16 for one class in C3).
   No installation or pool index overlaps between train and held-out.
   S_U contains unknown classes at class-dependent counts (e.g. 160-320 per class), S_V is class-balanced. The AUROC gap 0.915 (S_U) vs 0.671 (S_V) is therefore NOT explained by composition alone; a held-out-installation shift is a candidate but unproven.
   (Class names printed per combo here were taken from C1; do not read class names for C2/C3 from this note.)
3) H = harmonic mean of known accuracy and unknown recall (kr_modules._h, openset_metrics).
4) Timing: one full end-to-end pump run on sandbox CPU (adaptive_kr2 + VMD bank + gated K + LOIO guard, C1 fold1 seed0) took 2 min 25 s (4 threads, 30 GB RAM, peak use small). Estimate: 27 runs per arm ~ 66 min, 3 arms ~ 3.3 h. The trial result (H) is not used as evidence.
