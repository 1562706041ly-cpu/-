# 识别网络升级：难场景基准测试（2026-11-19）

完整数据表见 `summary.md`，逐次结果见 `bench.csv`（210 行：6 个场景 × 3 个模型 × 10 个种子，加上 3 个噪声场景的加宽 CNN 对照 × 10 个种子）。

## 为什么要换测试场景

在原来的干净 20-0 数据上，所有模型都在 99.5% 以上，200 个测试样本里最多差 1 个，什么改进都看不出来。所以先把测试变难，再比较模型。

## 设置

| 项目 | 内容 |
| --- | --- |
| 数据 | 东南大学齿轮箱公开数据（第 3 通道），5 类，每类 200 个窗口（窗长 2048，步长 1000）。20-0 工况的样本与你们的 `data_total.mat` 逐点一致 |
| 时频图 | v2.1 的同步提取变换 + 面积平均缩放。Python 版与 Octave 版逐像素相同 |
| 噪声 | 在连续信号上加高斯白噪声，SNR = 10 / 5 / 0 dB，训练、验证、测试都在同一噪声水平 |
| 少样本 | `few20`：每类只有 20 个带标签样本（15 个训练、5 个验证） |
| 跨工况 | 每个场景训练好的模型直接拿去测 30-2 工况的 1000 个样本（训练时完全没见过），噪声水平相同 |
| 划分 | 每类按时间顺序：训练 118 / 验证 38 / 测试 40，边界各留 2 个样本 |
| 训练 | 所有模型相同：Adam 1e-3，批大小 32，最多 60 轮，验证损失 8 轮不降就停 |
| LSSVM | fc1 64 维特征，BKA（种群 12、迭代 20）在训练+验证集上做 5 折交叉验证选超参数，测试集只预测一次 |
| 重复 | 10 个种子，所有模型用同一组种子，按种子配对做双侧精确 Wilcoxon 符号秩检验 |

参与比较的模型：

| 模型 | 结构 | 参数量 |
| --- | --- | --- |
| CNN | v2 基线，3 层卷积（16/32/64） | 2.8 万 |
| 加宽 CNN | 同上，通道加宽到 32/64/96，参数量和 ResNet 相当，用来排除"只是参数多了" | 8.2 万 |
| ResNet | 3 个残差块（16/32/64），分辨率路径和 CNN 相同 | 8.2 万 |
| ECA-ResNet | ResNet + ECA 通道注意力（每块多 3 个参数） | 8.2 万 |

## 主要结果（20-0 测试集准确率 %，10 次均值 ± 标准差）

| 场景 | CNN | CNN+LSSVM | ResNet | ResNet+LSSVM | ECA-ResNet | ECA-ResNet+LSSVM |
| --- | --- | --- | --- | --- | --- | --- |
| 干净 | 99.55 ± 0.69 | 99.70 ± 0.48 | 99.85 ± 0.24 | **100.00 ± 0.00** | 99.75 ± 0.42 | 99.45 ± 0.72 |
| 10 dB | 95.20 ± 1.81 | 97.65 ± 0.67 | 97.50 ± 0.91 | **98.35 ± 0.82** | 97.75 ± 1.21 | 98.25 ± 0.82 |
| 5 dB | 71.15 ± 7.76 | 81.95 ± 2.05 | 83.05 ± 2.45 | 85.70 ± 3.03 | 82.50 ± 2.58 | **85.90 ± 1.31** |
| 0 dB | 46.60 ± 4.12 | 53.60 ± 3.46 | 56.80 ± 2.63 | **59.60 ± 3.13** | 55.05 ± 4.09 | 58.25 ± 4.20 |
| 干净 + 每类 20 个 | 97.70 ± 1.46 | 97.35 ± 2.85 | 97.80 ± 0.35 | 96.70 ± 1.92 | 97.15 ± 0.91 | 97.65 ± 0.78 |
| 10 dB + 每类 20 个 | 68.50 ± 10.47 | 79.35 ± 3.84 | **82.15 ± 6.29** | 80.55 ± 4.54 | 80.50 ± 5.54 | 81.15 ± 4.14 |

5 类随机猜是 20%。

## 结论

1. **残差结构在噪声下有显著提升。** 只看网络自身输出,ResNet 比 v2 基线 CNN 高：10 dB +2.3 个百分点、5 dB +11.9、0 dB +10.2(p = 0.002–0.004,10 个种子里赢 9–10 次)。整条流程(+BKA-LSSVM)的提升小一些：5 dB +3.8(p = 0.002),0 dB +6.0(p = 0.010),10 dB +0.7(p = 0.074,不显著)。
2. **提升来自残差结构，不是参数变多。** 加宽 CNN 的参数量和 ResNet 一样，但网络自身输出反而比基线 CNN 差 3–6 个百分点。ResNet 比加宽 CNN 高 5.3–18.3 个百分点(p ≤ 0.004)。
3. **ECA 注意力没有带来提升。** ECA-ResNet 和 ResNet 在所有场景里都没有显著差别(p ≥ 0.06),0 dB 时平均还低 1.4–1.8 个百分点。答辩不能说"引入注意力机制提升了准确率"。
4. **BKA-LSSVM 在噪声下有用，网络越弱作用越大。** 对基线 CNN,10 / 5 / 0 dB 分别提升 2.5 / 10.8 / 7.0 个百分点(p ≤ 0.006);对 ResNet 提升 0.9 / 2.7 / 2.8(p = 0.010 / 0.008 / 0.031)。干净数据上没有显著作用;少样本场景只对基线 CNN 有用(10 dB + 每类 20 个:+10.9,p = 0.014),对 ResNet 和 ECA-ResNet 没有。之前在干净数据上 BKA-LSSVM 最多只多对 1 个样本，这是第一次看到几个百分点的提升。
5. **跨工况全部失败。** 所有模型在 30-2 工况上只有 22–39%,接近随机猜(20%)。换转速和负载后，齿轮啮合频率整体移动，时频图完全不同。换网络结构解决不了这个问题，需要专门处理(见下文)。
6. **少样本(每类 20 个)在干净数据上不难**,各模型都在 97% 左右，没有区别。加上 10 dB 噪声后差别才出来。

## 答辩建议

- 主模型用 **ResNet-BKA-LSSVM**(`config.m` 里 `cfg.cls.model = 'resnet'`,已设为默认)。可以讲成"残差特征提取 + 群智能优化的 LSSVM 分类器",两部分各有对照实验支撑。
- 想保留"注意力"的说法，可以用 ECA-ResNet,但只能说"准确率与 ResNet 相当"。
- 只报干净数据上的 99% 没有说服力。建议主报 5 dB 和 0 dB 的结果，配合"均值 ± 标准差 + 配对检验"。
- 跨工况失败要主动说，并作为下一步工作。

## 下一步建议

1. **解决跨工况**：最直接的是训练时混入多种工况的数据。更有技术含量的做法是阶次跟踪(按转速重采样，消除转速影响)或域自适应(如 DANN、MMD)。矿区设备工况变化大，这一步对实际部署最重要。
2. **用真实矿区噪声代替白噪声**：录一段风机、皮带、钻机的背景声，按同样的 SNR 叠加。`make_banks.py` 里只需要把 `standard_normal` 换成噪声录音片段。
3. **双分支融合(VMD 的 IMF + 时频图)**：在 5 dB、0 dB 场景下，这一步还有提升空间，也能把 VMD 模块真正接进识别流程。
