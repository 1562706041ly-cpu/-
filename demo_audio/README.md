# 界面试用录音

- `valve_id00_normal/`：MIMII 阀门 id_00 的 80 段正常录音（10 s，16 kHz，第 1 通道），从第 0–880 号录音中均匀抽取，用来“新建设备”。
- `test_120s_valve_id00.wav`：120 s 测试录音，由 12 段录音拼接：0–30 s 正常，30–50 s 异常，50–80 s 正常，80–90 s 异常，90–120 s 正常。
  这些测试录音没有参与建模。

试用：登录 → 新建设备（选 `valve_id00_normal` 文件夹）→ 分析录音（选 `test_120s_valve_id00.wav`）。
服务器上的结果（窗口步长 10 s）：40–50 s 和 80–90 s 告警，30–40 s 的异常漏报，正常时段没有误报。
3 段异常检出 2 段，和实验中这台设备的水平一致。

注意：最初只用第 0–79 号录音建模时，后面的正常录音也被误报（声音随时间有漂移）。
实际建模时，正常录音要覆盖不同时间段和不同工况。
